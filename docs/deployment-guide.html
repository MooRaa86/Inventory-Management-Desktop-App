Inventory Manager

Deployment Guide — Folder Structure, Database Location & Migration to Another PC

1. Folder Structure

The entire application lives in a single portable folder. Here is the complete layout:

    |-- inventory-backend.jar    ← The application server
    |

    |-- data/

    +-- logs/

2. Where Is the Database?

Your entire database — all products, stock movements, purchases, issues, users, settings, and audit logs — is stored in a single SQLite file:

Location: InventoryManager/backend/data/inventory.db
This is the only file you need to worry about. Everything else is the application itself.

3. Moving to Another PC

The application is fully portable. No installation is required on the target machine.

Prerequisites

  • Windows 10 or later (64-bit)
  • No Java, Node.js, or any other software needs to be installed

Step-by-Step

1 Close the application on the current PC (close the window).
2 Copy the entire InventoryManager folder to a USB drive, shared network folder, or any transfer method you prefer.
Example: Copy D:\InventoryManager → E:\InventoryManager (USB drive)
3 Paste the folder on the new PC (e.g., C:\InventoryManager).
4 Double-click start.cmd to launch the application.
5 The browser will open automatically. Log in with the default credentials:
Username: admin
Password: admin@omar.com
Note: These default credentials are the same on every installation. For security, change the admin password after first login (go to Settings → Change Password).

4. Fresh Start (Optional)

If you want a clean installation on the new PC with no data from the old one:

  1. Copy only the app/, electron/, runtime/, and start.cmd files
  2. Do not copy the backend/data/ folder
  3. On first launch, a fresh empty database will be created automatically

5. Backing Up Your Data

You can create backups from within the application:

  1. Go to Backups in the sidebar
  2. Click Create backup
  3. Click Download to save the backup zip to your computer

A backup contains everything: database, settings, and metadata. You can restore it on any installation of the same application.

7. Troubleshooting

ProblemSolution
start.cmd opens and closes immediatelyCheck if another instance is running (close it first). Or check backend/logs/application.log for errors.
Port 8475 already in useAnother instance is running. Close it or restart the PC.
"Access denied" on start.cmdRight-click → Run as Administrator, or move the folder to C:\ or D:\ (not Desktop or Downloads).
Database is empty after movingYou may have copied without the data/ folder. Copy the full backend/data/ folder.
Windows SmartScreen warningClick "More info" → "Run anyway". This is normal for unsigned apps.

8. File Size

The full portable folder is approximately 350–400 MB. This includes the Electron desktop shell, bundled Java runtime, and the application server.
